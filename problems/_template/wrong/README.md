# wrong/

放**必须被数据杀干净**的错解，每个文件一个。`oj attack` 要求它们全部 0 分。

从标程派生，六类各来一个：

| 文件 | 变异 | 打的是什么 |
| :-- | :-- | :-- |
| `overflow.cpp` | `long long` 改回 `int`，或答案不取模 | 值域边界 |
| `quadratic.cpp` | `sort` 换 `O(n^2)`，堆换线性扫描 | 时限 |
| `missing_dim.cpp` | DP 少一维状态 / 少一个约束 | 建模完整性 |
| `greedy.cpp` | DP 换成"看起来对"的贪心 | 正确性证明 |
| `no_edge.cpp` | 删掉 `n==1` / 空集 / 全等 的特判 | 退化数据 |
| `overfit.cpp` | 只处理某个子任务，其余输出垃圾 | 子任务独立性 |

某个错解拿不到 0 分，说明对应子任务的数据不够强——补模板，不要改错解。
